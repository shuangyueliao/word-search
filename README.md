# Word Search · 单词搜搜乐

Free single-file HTML5 word-find puzzle. 12 themes, three grid sizes
(8×8 / 10×10 / 12×12), 8 words per 180-second round, highlighter drag
with 8-direction snapping, crayon strike lines, star ratings and
per-theme best scores. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/word-search/

- Mouse / touch drag across letters in all 8 directions, WebAudio sounds
- Procedural paper-style visuals, no dependencies, no tracking
