# Word Search — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Find hidden words in a letter grid! Drag across the letters in any of 8
directions. 12 themes, 3 grid sizes, 180-second rounds. A relaxing word
puzzle for all ages — how fast can you spot all 8?

## Details

- Genre: Puzzle / Word / Casual
- Controls: Mouse / Touch — drag from the first letter to the last letter.
- Features: 12 themes (Animals, Food, Countries, Sports and more),
  8×8 / 10×10 / 12×12 grids, 8 words per round, 180-second timer with a
  +5s bonus per word, star ratings by finish time, best scores saved per
  theme and grid size, procedural graphics & sounds, single-file HTML5
  (no external assets), works offline once loaded.
- Tech: Vanilla JavaScript, Canvas, WebAudio. No frameworks, no tracking.
